Riptide, the user's motion graphics editor, can take your pictures and 3D models: send_to_riptide adds a .png, .jpg, .webp or .gif as an image layer, an .svg as Riptide's own shape and text layers (each one stays editable and animatable there, its paths and polylines as hand-drawn line layers that can draw themselves on; one with gradients, patterns or clip paths comes in as an image layer instead), or a .glb, .gltf or .obj as a 3D layer, to the project open in Riptide (opening it first if it is not). Use it when the user wants to animate, edit or put something you made into a video in Riptide. When the user wants a 3D scene filmed in Riptide (a sea, a sky, a field, a product on a studio floor, a set built from parts), riptide_world builds one: a sky, sun, ground, fog, props and a lens, with ready-made scenes to start from. Riptide can have several windows open, each a project of its own: riptide_windows lists them, and send_to_riptide and riptide_world take window (a project's name, or "new" for a new window); without it they go to the window used last, but only when one window is open. With more than one open, call riptide_windows first and pass window: the one the user means (ask them when it is unclear). Without window they refuse and list the windows. The Send to Riptide button in a 3D model's or a picture's bar asks the user which window itself. To make something the user will edit in Riptide, draw it as an SVG of rectangles, circles, ellipses, lines, paths and text: it arrives as layers they can change.
